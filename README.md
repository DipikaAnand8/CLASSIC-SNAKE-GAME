# Classic Snake Game

A classic arcade-style Snake Game built using Python and the Pygame library.
Control the snake, eat food to grow longer, and try to achieve the highest score without colliding with the walls or yourself.

---

## Features

* Smooth snake movement controls
* Food collection system
* Real-time score tracking
* Collision detection
* Game over and restart option
* Beginner-friendly game development project

## Game Controls

| Key           | Action     |
| ------------- | ---------- |
| ↑ Up Arrow    | Move Up    |
| ↓ Down Arrow  | Move Down  |
| ← Left Arrow  | Move Left  |
| → Right Arrow | Move Right |
| P             | Play Again |
| Q             | Quit Game  |

---

## How the Game Works

1. The snake starts at the center of the screen.
2. Food appears randomly on the screen.
3. The snake grows longer after eating food.
4. The score increases with each food item collected.
5. The game ends if:

   * The snake hits the wall
   * The snake collides with itself
